# 📈 MOEX Signal Bot

[English version →](README.md)

Бот торговых сигналов для Московской биржи. Сканирует ликвидные российские
акции на аномалии объёма, подтверждает их техническими индикаторами и
новостями из RSS, и умеет выставлять **бумажные сделки** в песочнице
T-Investments.

Вместе с ботом опубликован инструментарий, которым проверялось, стоит ли этой
стратегией вообще торговать. Честный ответ пока — **нет**. См.
[Честная оценка](#-честная-оценка-прочитай-сначала-это).

---

## ⚠️ Честная оценка (прочитай сначала это)

> Бэктест на 4 годах / ~3200 сделках показал: у ядровой стратегии (объёмная
> аномалия + уровни) **нет устойчивого преимущества, которое переживает
> издержки**. Высокий винрейт обманчив — матожидание после комиссии и спреда
> около нуля или отрицательное.
>
> Бот работает **только в песочнице** (бумажные деньги). Переводить его на
> реальные деньги нельзя, пока `--edge` не покажет статистически значимый
> плюс на большой выборке.

Репозиторий опубликован как инженерный и исследовательский артефакт —
добросовестная попытка найти edge вместе с инструментами, которые доказали,
что edge там нет. Это **не** система заработка, **не** инвестиционная
рекомендация и поставляется без каких-либо гарантий. Торговля несёт риск
полной потери средств.

---

## Что делает

- Тянет дневные и внутридневные свечи через **MOEX ISS API** (бесплатно, без
  ключа) и опционально через **T-Invest API** (стакан, портфель, песочница)
- Детектирует аномалии объёма (объём > 2× от среднего за 20 дней) с фильтром
  по минимальному абсолютному обороту
- Подтверждает сигнал через RSI(14 Уайлдера), MA20/MA50, ADX(14), уровни
  Фибоначчи, сжатие Боллинджера, OBV и пересечения MA
- Парсит новости из RSS российских финансовых СМИ с дедупликацией через кэш
- Опционально оценивает новости через **Anthropic API** в контексте рынка
  (ставка ЦБ, USDRUB, IMOEX, Brent, Gold)
- Синтезирует всё в score и выдаёт сигнал **LONG** / **SHORT** с точкой входа,
  стопом по ATR и тремя тейк-профитами
- Отправляет сигналы и ежедневный EOD-отчёт в **Telegram**
- Выставляет ордера в песочнице с расчётом размера позиции и риск-лимитами

## Требования

- Python 3.10+
- Доступ в интернет к `iss.moex.com`
- Опционально: ключ Anthropic API, Telegram-бот, токен T-Invest

## Установка

```bash
git clone <адрес-репозитория> trader
cd trader
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

SDK T-Invest опционален и **отсутствует** на публичном PyPI:

```bash
pip install t-tech-investments --index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple
```

Без него бот работает на бесплатных данных MOEX ISS, но торговля в песочнице,
стакан и портфель недоступны. Проверить установку: `python3 check_sdk.py`.

## Настройка

```bash
cp .env.example .env
```

Дальше заполни `.env`. Все значения опциональны:

| Переменная | Назначение |
|---|---|
| `ANTHROPIC_API_KEY` | AI-анализ новостей. Без него модуль просто пропускается. |
| `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления. Без них — вывод в консоль. |
| `TINVEST_TOKEN` | Данные T-Invest + песочница. Без него — только MOEX ISS. |
| `TINVEST_SANDBOX_ACCOUNT_ID` | Заполняется через `--create-sandbox`. |
| `CBR_KEY_RATE` | Ключевая ставка ЦБ, обновляй после каждого заседания. |
| `SANDBOX_MAX_*_PCT` | Размер позиции и лимиты концентрации. |
| `ENABLE_REAL_TRADING` | Оставь `false`. Реальные ордера — заглушка. |

`.env` в `.gitignore`. **Никогда не коммить его.** Остальные настройки
(`STOP_ATR_MULT`, `WEEKLY_*`, `NEWS_*`, `RECENT_PERF_*`, …) имеют дефолты в
коде — прописывай их, только чтобы переопределить.

Разовая настройка sandbox-счёта:

```bash
python3 tinvest_data.py --create-sandbox
python3 tinvest_data.py --fund-sandbox
python3 tinvest_data.py --portfolio
```

## Запуск

```bash
./run.sh                 # один скан, вывод в терминал
./run.sh --watch         # фоновый режим, пересканирование каждые 5 мин
./run.sh --news-only     # только новости, без рынка
```

Либо напрямую:

```bash
python3 moex_bot.py --watch
python3 moex_bot.py --trade-log      # показать лог сделок
python3 moex_bot.py --export-csv     # выгрузить сделки в CSV
python3 moex_bot.py --edge           # реален ли edge или это удача
python3 moex_bot.py --close SBER     # закрыть позицию вручную
```

Ежедневный отчёт в Telegram (cron, 19:00 МСК):

```bash
0 16 * * 1-5 /полный/путь/до/trader/run_report.sh >> /полный/путь/до/trader/logs/report.log 2>&1
```

## Исследовательский инструментарий

Это самая интересная часть. Каждый инструмент сделан, чтобы стратегию
**опровергнуть**, а не приукрасить.

### `backtest.py` — проверка идеи на истории

Прогоняет реальные функции бота по 2–4 годам истории MOEX с честными
издержками и проверкой вне выборки (out-of-sample). Любую новую гипотезу
проверяй здесь **до** изменения боевого бота.

```bash
python3 backtest.py --years 4 --commission 0.10 --split   # baseline + OOS
python3 backtest.py --years 2 --regime --split            # trend-following
python3 backtest.py --years 2 --direction SHORT           # только шорты
```

Ключевые флаги: `--quality`, `--min-vol-ratio`, `--type`, `--direction`,
`--tier 1|2`, `--regime` (по тренду IMOEX), `--split` (OOS), `--csv out.csv`.

### `moex_bot.py --edge` — реален ли edge

Считает матожидание на сделку **после издержек**, 95% доверительный интервал и
t-статистику по `trade_log.json`. Вердикт честный: при малой выборке (<30) или
интервале, пересекающем ноль, — «преимущество не доказано». Эта же строка
добавляется в ежедневный EOD-отчёт в Telegram.

### `strategy_lab.py` — семейства стратегий против «купи и держи»

Честный бенчмарк профессионала — buy & hold, который большинство активных
управляющих не обыгрывают после издержек. Модуль сравнивает `bh`, `tsmom`
(цена > MA200), `ma_cross` (MA20/MA100) и `rsi2` (возврат к среднему по
Коннорсу): long-only, equal-weight, вне выборки.

### `brute_force.py` — перебор параметров с защитой от переобучения

Перебрать сотни конфигов и взять лучший на истории — надёжный способ выдумать
несуществующий edge. Конфиг считается кандидатом, только если проходит **все**
фильтры: положительная доходность в *обеих* независимых половинах окна,
полная доходность выше безрисковой ставки и ранжирование по *худшей* половине,
а не по лучшей.

```bash
python3 brute_force.py --from 2016-01-01 --to 2021-12-31
```

### `pulse_tracker.py` — объективная проверка чужих прогнозов

Превращает «у трейдера +132%» в проверяемую статистику. Витринные проценты не
проверяемы (искажаются вводами и выводами), но публичные *прогнозы*
falsifiable. Трекер фиксирует цену на момент прогноза и беспристрастно считает
результат по котировкам MOEX. Доступ к чьим-либо счетам не нужен — только
публичные данные.

```bash
python3 pulse_tracker.py add --ticker IMOEX --target 2480 --horizon 7
python3 pulse_tracker.py add --ticker SBER --dir long --horizon 5
python3 pulse_tracker.py score     # подтянуть котировки, закрыть прогнозы
python3 pulse_tracker.py report    # % сбывшихся, P&L копирования vs buy & hold
```

### `FORWARD_TEST_MODE` — набор статистики в песочнице

Боевые throttle-гейты сжимают торговлю до ~6 сделок в год — выборку для
`--edge` так не набрать. Флаг ослабляет **только** эти throttle-гейты; жёсткая
защита (`MAX_DAILY_LOSS_PCT`, `MAX_STOP_PCT`) остаётся активной.
**Только для песочницы.**

```bash
FORWARD_TEST_MODE=1 python3 moex_bot.py --watch
```

## Структура проекта

| Файл | Роль |
|---|---|
| `moex_bot.py` | Основной бот: сканирование, score, сигналы, ордера, Telegram |
| `tinvest_data.py` | T-Invest API: котировки, история, стакан, песочница |
| `daily_report.py` | Ежедневный EOD-отчёт в Telegram |
| `moex_signal_bot.py` | Автономный минимальный сканер (первый прототип) |
| `backtest.py` | Исторический бэктест ядровой стратегии |
| `strategy_lab.py` | Семейства стратегий против buy & hold |
| `brute_force.py` | Перебор параметров с защитой от переобучения |
| `pulse_tracker.py` | Объективный трекер публичных прогнозов |
| `check_sdk.py` | Диагностика установки T-Invest SDK |
| `test_bot.py` | Набор тестов (152 шт.) |
| `run.sh`, `run_report.sh`, `export_logs.sh` | Запуск, отчёт, экспорт данных |

Runtime-состояние (`signals_state.json`, `trade_log.json`, логи `*.jsonl`,
кэши, `logs/`) создаётся при запуске и находится в `.gitignore`.
